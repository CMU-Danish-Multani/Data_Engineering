Stock Intelligence Dashboard: High-Level Design

Team 8: Mohd Danish Multani, Anav Batra, Akshay Iyer, Alan Zhou · November 18, 2026

  • Get the data. Six feeds from SEC EDGAR, Yahoo Finance and Alpha Vantage, one Python job each, run by cron.
  • Keep the original. Every file lands in S3 unchanged, so any later step can rerun without calling the APIs again.
  • Numbers in PostgreSQL. Raw tables, then staging (clean and check), then a star schema, then 16 KPI views.
  • Text in MongoDB. Earnings releases and call transcripts, cut into passages with embeddings for search by meaning.
  • Two retrieval databases. The dashboard and the assistant read PostgreSQL for numbers and MongoDB for text, through read-only logins.
  • Traceable. The ops tables log every run and quality check, so each number leads back to its source file.
